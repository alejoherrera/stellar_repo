1. Concepto

Un publisher de Monitor as a Service ancla en Stellar la integridad de observaciones de obra pública (datos + imágenes producidos por sistemas de IA como dIAra). El contenido vive en IPFS, content-addressable. Cualquiera puede:

  1. Leer la cuenta del publisher en Horizon (público, sin auth).
  2. Recuperar el contenido desde cualquier gateway IPFS público.
  3. Recalcular SHA-256 y comprobar que coincide con el ancla on-chain.

Eso significa que vos no dependés de nuestra API. Si esta página o la convenience API caen, la data sigue ahí, verificable, accesible. Lo único que necesitás es el schema y la public key del publisher.

4. Quickstart en 30 segundos

Bash + jq

ACCOUNT="GDRWQERI6PI3WICTGPJBFBEFRV7ZRLCWG3IRA2YZQA5ZINHPY23JCPFR"
HORIZON="https://horizon-testnet.stellar.org"

curl -s "$HORIZON/accounts/$ACCOUNT" | jq '.data | keys[] | select(startswith("diara:"))' | head

Python (con SDK)

pip install -e ./sdk/py  # desde el repo

from monitor_as_a_service import Client

client = Client.testnet("GDRWQERI6PI3WICTGPJBFBEFRV7ZRLCWG3IRA2YZQA5ZINHPY23JCPFR")
for o in client.outputs():
    print(o.output_id, o.workers, o.phase, o.image_url)

# Verificación criptográfica:
result = client.verify("20251029-060211")
print("JSON match:", result.json_ok, "Image match:", result.image_ok)

JavaScript (browser, sin build)

<script type="module">
  import { Client } from "/static/monitor-as-a-service.js";
  const client = Client.testnet("GDRWQERI6PI3WICTGPJBFBEFRV7ZRLCWG3IRA2YZQA5ZINHPY23JCPFR");
  const outputs = await client.outputs();
  console.log(outputs.length, "anchors found");
</script>

7. Acceso directo (sin SDK)

Cuando el SDK no esté disponible para tu lenguaje, podés implementar un cliente con tres pasos: leer Horizon, decodear base64, y opcionalmente fetchear desde IPFS para verificar. 

# Listar todos los outputs anclados (key + valor base64)
curl -s "https://horizon-testnet.stellar.org/accounts/GDRWQERI6PI3WICTGPJBFBEFRV7ZRLCWG3IRA2YZQA5ZINHPY23JCPFR" \
  | jq '.data | to_entries | map(select(.key | startswith("diara:")))'

# Leer maquinaria de un output específico
curl -s "https://horizon-testnet.stellar.org/accounts/GDRWQERI6PI3WICTGPJBFBEFRV7ZRLCWG3IRA2YZQA5ZINHPY23JCPFR" \
  | jq -r '.data["diara:20251029-060211:machinery"]' | base64 -d

Ver SCHEMA §7 para más ejemplos.

8. Ideas para construir

Bot de Telegram / Discord

Postea cuando entra un nuevo ancla, o cuando se detecte una anomalía (ej. workers=0 en hora laboral, hito sin evidencia, atraso en cronograma).

Timelapse animado

Reproducí las imágenes de una obra como timelapse usando los CIDs en orden cronológico — con verificación criptográfica visible.

Mapa interactivo

Cuando se agreguen coordenadas geográficas a la metadata, mapear obras activas con popup por output.

Email digest

Resumen semanal automático: ¿qué obras tuvieron actividad? ¿cuántas personas-hora? ¿qué etapa constructiva avanzó?

Dataset OSINT en CSV

Cron que dumpea todo a CSV/Parquet diariamente y lo publica para uso de periodismo de datos. Ver examples/03_export_csv.py.

Verificador independiente

App que solo se dedique a re-pinear contenido en otros nodos IPFS y atestiguar su recuperabilidad — un "second IPFS notary".
